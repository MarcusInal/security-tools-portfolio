Python Security Tools
A collection of command-line tools developed during my studies in Systems Science to practice offensive security concepts and automation.

Included Tools
Recon Tool: A multi-threaded network scanner that performs port scanning and host discovery (ICMP).

OSINT Extractor: A script using RegEx to parse unstructured data for contact information.

Web Checker: A utility to monitor the status of multiple web endpoints concurrently.

Tech Stack
Language: Python 3

Libraries: socket, threading, argparse, requests, re
